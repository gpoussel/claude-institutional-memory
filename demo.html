i.
The premise

Memory isn't a database. It's a decision.

Brief / 90 sec

Most people hear "memory" and picture a vector store of documents. It isn't. Memory is the agent deciding what to keep, what to forget, and what to overwrite when the world disagrees with what it thought yesterday. Three sessions on one domain. The truth changes between them. Someone tries to slip a bad fact past it. By the end, the agent should know — and admit — what changed.

iv.
Under the hood

Four moving parts.

Runtime
Managed Agents

No infra to wire up. The agent loop, tool dispatch, and session lifecycle live on Claude's platform.

Persistence
Memory Tool

Reads and writes structured markdown to /mnt/memory/, scoped per agent ID.

Curation
Curator Sub-agent

A second agent reviews fresh writes, merges duplicates, and retires stale facts.

Context
Files API

Round-by-round document ingestion. The context grows; the memory store stays curated.
